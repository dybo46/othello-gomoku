# othello-gomoku

オセロ・五目を作った記録と、見た目・音・演出を試せるCPU専用デモです。利用者が自分のQNAPやサーバーに設置できるよう、ネット対戦対応のコードと設置資料も収録しています。

**このプロジェクトから作者のQNAPへ接続することはありません。** 作者のゲームへ人を集める入口ではありません。公開デモと作者の運用環境は分離しています。

制作記録：[GitHubリポジトリ](https://github.com/dybo46/othello-gomoku)

試遊：[CPU専用デモ](https://dybo46.github.io/othello-gomoku/)

## 収録内容

| 場所 | 内容 |
|---|---|
| `docs/` | GitHub Pagesで動くCPU専用デモ。CPU対戦10段階・CPU同士の観戦。ゲーム用APIは不要です。 |
| `self-host/` | 利用者自身のサーバーに設置するネット対戦対応版。作者のサーバーへの接続先は含みません。 |
| `AGENTS.md` | AI向けの作業指示書。公開用と私用環境を混ぜない方針を記録。 |
| `HISTORY.md` | 現在までの制作内容・変更履歴の要約。 |
| `SNAPSHOT.json` | この記録版の出発点とファイル構成の情報。 |
| `SELF-HOSTING.md` | 自分のPC・QNAP・サーバーへの設置資料。 |
| `PAGES.md` | GitHub PagesでCPU専用デモを公開する方法。 |
| `LICENSE-STATUS.md` | 公開前に決める利用条件と素材の記録。 |

現在の記録元は完成版 **v2.6**。オセロと五目の両方を遊べます。五目は15路（15×15の交点）、黒白とも5個以上で勝利、禁手なしです。

オセロの背景20種類、石3種類、変化の演出21種類、合成音、CPU10段階、CPU観戦、先手後手の抽選、1手の制限時間、パス、降参、CPU戦の待った・任意の合法手マーカー、黄色い最後の着手、スマート/標準/拡大サイズ、別枠に対応します。対局中に石数を示さず、終局後に並べて集計します。

## CPU専用デモを手元で開く

Node.js 24以上で、プロジェクトのフォルダーから実行します。外部パッケージは不要です。

```text
npm run demo
```

表示されたローカルURLを開きます。初期URLは `http://127.0.0.1:8793/othello-gomoku/` です。名前を入れる画面はCPU戦用の表示名設定であり、どこかの部屋への入室ではありません。GitHub Pagesと同様にゲーム用サーバーやQNAPへ接続せず遊べます。ファイルのダブルクリックではなくHTTP経由で開いてください。

## 自分のサーバーでネット対戦する

`SELF-HOSTING.md`を参照してください。同じ自分のサーバーを開いた人同士で対戦・観戦する仕組みです。GitHub PagesのCPUデモから自動的に接続することはありません。

## 記録の位置付け

初回記録版v1.3を履歴に残し、今回の完成版v2.6をもとに、作者の環境への入口を取り除き、CPU専用デモを分離した記録用スナップショットです。元の開発・運用フォルダーと自動同期せず、作者のQNAPも更新しません。過去の全Gitコミットを移植したものではなく、v1.3とv2.6の記録版と制作経緯の要約です。

GitHubで制作記録を公開し、PagesでCPU専用デモを公開するためのプロジェクトです。公開用の利用条件はまだ確定していません。

## 検証

```text
npm test
npm run test:self-host
```

前者はAPIを使わないデモ・相対パス・個人環境の混入を、後者は共通ルール・CPU・待受などを確認します。確認記録は `VERIFICATION.md` に残します。


## v2.6で追加した内容

- 五目のCPU対戦・CPU観戦10段階。1〜8は遊びやすく、9〜10は難しめ。ときどき甘い手が続くほか、後半の強さに試合ごとの変化があります。勝敗を強制する仕組みではありません。
- 五目18盤面とテーマ別の黒白の石。木、サイバー、大理石、透明ガラスや宝石など。背景と石・線・音を独立して追加できます。
- 無料の追加着手音20種（全CC0、出典同梱）と試聴、試合ごとに音を変えるランダム。従来の碁石の合成音はそのまま。
- 難易度1〜10ボタン、ゲーム選択、降参時の石の飛散5演出、局面に合わせた五目の実況風コメント。
- 拡大表示、五目の終了画面を薄くする処理と「盤面を確認」、オセロの結果の黒白表示修正、7文字の表示名と追加ランダム名。
- 自己設置版はCPU練習中のネット待機・自動対戦開始にも対応。PagesはCPU専用でオンラインへ接続しません。

CPUの対局内容や勝利記録は永続保存しません。見た目・音などの個人設定だけをブラウザに保存します。
