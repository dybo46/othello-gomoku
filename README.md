# othello-gomoku

オセロ・五目を作った記録と、見た目・音・演出を試せるCPU専用デモです。利用者が自分のQNAPやサーバーに設置できるよう、ネット対戦対応のコードと資料も収録しています。

**作者のQNAPへ接続する入口は含みません。** GitHubは作品の記録・試遊・自分で設置するための配布場所です。

[CPU専用デモで遊ぶ](https://dybo46.github.io/othello-gomoku/) ／ [自分のサーバーへの設置方法](SELF-HOSTING.md) ／ [AI向け作業指示書](AGENTS.md)

### 好きな盤と音で遊ぶ

- オセロ：20背景、3種類の駒、21種類の石の変化演出。対局中は石数を出さず、最後に並べて集計します。
- 五目：15路、黒白とも5個以上で勝利、禁手なし。92スキンと、それぞれの背景に合う濃淡2種類の駒。
- 五目の着手音：63種類のCC0素材と13カテゴリー。個別選択、置くたびのカテゴリーランダム、試合ごとのランダム、重み付き「デフォルト」。出典と利用条件は素材に同梱。
- CPUは両ゲーム10段階。観戦結果の「この戦いをずっと見続ける」で、終了から6秒後に次戦を繰り返します。
- 背景スキンだけは保存せず、次回・退出後はランダム。音や駒などの設定は保存。同じプレイを別枠へ移す場合は背景も引き継ぎます。
- スマート・標準・拡大・激拡大・爆拡大と縦長/横長、別枠、黄色い最後の着手、降参演出、CPU戦の待ったに対応。

### 自分で設置すれば、友人と同じ部屋へ

オンライン版には、チャット、CPUと対戦しながらの順番待ち、勝者の待受継続、win・現在連勝・最高連勝を収録しています。「誰でも」は初期OFF。双方がチェックして待受中なら、上の対局中でも別の2人が対戦できます。各組の上の人の希望ゲーム・持ち時間を採用します。対局中の参加者をクリックして観戦先を変えられ、対人戦中は自身の対局が優先です。

これらは**自己設置版の機能**です。PagesのCPU試遊から、どこかのオンライン部屋へ自動接続する機能はありません。

## 手元でCPU試遊を開く

Node.js 24以上で、プロジェクトのフォルダーから実行します。外部パッケージは不要です。

```text
npm run demo
```

表示された `http://127.0.0.1:8793/othello-gomoku/` を開きます。名前はCPU戦の表示用で、サーバーへの入室ではありません。ファイルのダブルクリックではなくHTTP経由で開いてください。

## 自分のPC・QNAPへ設置する

`SELF-HOSTING.md`を参照してください。同じ設置先を開いた人同士で対戦します。作者の接続先や認証情報は収録しません。CPUデモの公開方法は`PAGES.md`、操作方法は各版の「遊び方」で確認できます。

## 検証

```text
npm test
npm run test:self-host
```

公開情報・相対パス・PagesのAPI非依存と、自己設置版のルール/CPU/待受/チャット/同時対局を検証します。`VERIFICATION.md`に結果を記録します。
