# 五目の着手音・出典と利用条件

v3.0の70音からユーザー指定7音を除外し、現在63音。全てCC0 1.0。コピー・加工・ゲームへの同梱・GitHubでの音声ファイル再配布が可能です。利用報告・クレジットは必須ではありませんが、作者と出典リンクを任意の謝辞として同梱します。作者によるゲームの推奨を意味しません。

CC0の説明：https://creativecommons.org/publicdomain/zero/1.0/

## 加工と出典の記録

manifest.jsonに各原音・配布ファイルのSHA256、元ファイル名、作品ページ、作者、切り出し位置を保存。新50音はモノラルPCM16/44.1kHz、先頭の無音を除き着手用の短い音へ加工。ピークと平均音量を抑え、短いフェードを適用。音程は変更していません。既存20音の音声は変更していません。元は物体音・効果音の素材であり、クリスタル等の名称はスキンに合わせたイメージ分類を含みます。

囲碁の実録5音はbillhails2の1作品内にある異なる5着手を切り出したものです。5作品と誤記しません。Freesoundは公開HQ試聴MP3を使用。Kenneyの新規音は作者本人がOpenGameArtで公開した同一パックから取得しています。

## ランダムの種類

- カテゴリー名＋ランダム：置くたびに、そのカテゴリー内から直前と異なる音を選びます。
- 試合でランダム：従来どおり1試合に1つの個別音を選びます。
- ゲームは同梱ファイルだけを読み、再生時に外部サイトへ接続しません。初期選択はv3.1の「デフォルト」（試合ごとに音の方式を抽選）。従来の合成goも個別に選べます。
